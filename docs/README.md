# docs

The connective tissue over the rest of the repo: the knowledge base behind
it, an honest account of what's borrowed versus mine, a comparison of how
practice differs across agentic coding tools, and the index of everything
else.

- **`lessons.md`** - 30 project-agnostic operational lessons, each with the
  observation, the rule it implies, and how the rule is actually enforced.
  Mined from my own operational notes and stripped of every identifier.
- **`sources.md`** - the honesty document. What in this repo is an adopted
  convention (with a citation), what's community practice I learned from
  without copying literally, and what's my own practice, not dressed up as
  either.
- **`tool-differences.md`** - where practice actually differs between
  agentic coding tools: which instruction file each one reads, skills versus
  commands versus subagents versus plugins, hooks versus prompt instructions,
  and MCP as the shared tool-server layer underneath all of them.
- **`INDEX.md`** - the index of the whole repository: every top-level
  section, every file in it, one line on what it is and when to copy it.
  This is the file the root `README.md` points at.
