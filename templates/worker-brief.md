# Worker brief

How to use this: this is a stub, not the template. The canonical worker
brief template lives at
[`orchestration/worker-brief-template.md`](../orchestration/worker-brief-template.md).
Use that one when dispatching a worker; it covers scope, the standing rules
every worker needs, and the report format.

This file exists only so `templates/` has an entry point for "I need to
brief a worker" without duplicating a template that `orchestration/` already
owns and keeps up to date.
